# MandaStrong Studios

AI-Powered Creative Platform with 600+ tools for video, image, audio, and text processing.

## Features

- **Editor's Choice**: Curated collection of premium AI tools with ratings and reviews
- **Full-Screen Upload**: Professional media viewer with complete playback controls
- **600+ AI Tools**: Comprehensive catalog with search and category filtering
- **Responsive Design**: Beautiful, production-ready interface

## Pages

- **Home**: Hero section with platform overview
- **Tools**: Browse and search 600+ AI tools
- **Editor's Choice**: Hand-picked premium tools
- **Upload**: Full-screen media viewer with controls
- **Pricing**: Three-tier pricing plans
- **About**: Company story and mission

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Database

This project uses Supabase for data persistence.
